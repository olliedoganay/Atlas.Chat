# Atlas Chat v1.3.1

Release date: 2026-08-20

Atlas Chat 1.3.1 is the release-integrity patch for 1.3.0. It contains the complete 1.3 feature set plus the final runtime privacy and packaging fixes discovered during post-publication verification.

## Runtime and security hardening

- Docker invocation failures and daemon diagnostics are retained in bounded local logs but no longer flow through the runner-status API to the renderer.
- The existing non-Windows encryption-key derivation remains byte-for-byte compatible with encrypted Atlas data. Fixed compatibility vectors document that its input is a validated or generated 256-bit OS-keyring master key, not a user password.
- The corresponding CodeQL password-hashing result is recorded as a reviewed false positive, while the genuine Docker exception-exposure finding is fixed.

## Release integrity

- Linux and Windows installers are normalized to their final dotted GitHub download names before checksum manifests are generated.
- Collision checks prevent normalization from overwriting another staged artifact.
- Platform manifests and the aggregate `SHA256SUMS.txt` therefore work directly with files downloaded from the GitHub release.
- The published v1.3.0 manifests were corrected in place without replacing any installer binary; v1.3.1 includes the durable workflow fix.

## Test reliability

- The Ollama model-inspection deadline regression now verifies one bounded batch wait, cancellation of pending probes, nonblocking executor shutdown, and tag fallbacks without depending on host scheduler timing.

## Verification

The v1.3.1 candidate repeats the full Linux, Windows, and macOS CI matrix, Python and JavaScript/TypeScript CodeQL analysis, dependency audits, 421 backend tests, 149 frontend tests, Rust/Tauri checks, and all six installer builds before publication.
